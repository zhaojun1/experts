## 精简版 SOP（三阶段流程）

### Phase 1：议题拆解

阅读用户问题，拆解为 **2-5 个核心议题**（根据话题复杂度决定，简单问题2-3个，复杂话题可到5个）。

拆解原则：
- 每个议题对应一个决策维度
- 典型议题：① 企业质量与护城河 ② 财务健康与估值 ③ 风险与最坏情况 ④ 战略竞争格局 ⑤ 行业趋势与成长空间

输出议题清单，**注明每个议题相关的分析师**（不相关的分析师该议题不参与，留空即可）。

#### 🔴 CHECKPOINT：议题拆解确认

输出拆解结果后，**必须暂停等待用户确认**，展示以下内容：

```
📋 议题拆解结果

| # | 议题 | 参与分析师 |
|---|------|-----------|
| 1 | [议题描述] | [分析师ID列表] |
| 2 | [议题描述] | [分析师ID列表] |
| ... | ... | ... |

请确认议题拆解是否合理，回复"继续"进入发言阶段，或提出调整意见。
```

**🛑 STOP — 用户确认后才能进入 Phase 2**。如果用户提出调整（增减议题、变更参与分析师），修改议题清单后重新展示确认。

---

### Phase 2：按议题发言（限制轮次）

对每个议题，依次调度相关分析师：

**调度规则**：
1. **不相关的分析师直接跳过，无需发言**（0次是允许的）
2. 相关分析师首轮发言，输出结论性观点
3. 如有明显争议或补充需要，可请求第2轮
4. 如仍有分歧，最多第3轮最终立场确认
5. **严禁超过3轮**，超出则直接结题

**发言限制规则（核心）**：
- 每位分析师每个议题：**0-3次发言**（不相关可以完全不参与，不强制）
- 分析师自主判断相关性——如果某议题与自己专业领域关系不大，直接跳过
- 没有反复辩论拉锯，分析师输出结论性观点，不需要互相回应再回应

**议题发言参考**（非强制，分析师可自主决定是否参与）：

| 议题类型 | 高度相关（建议参与） | 可选参与 | 通常跳过 |
|---------|------------------|---------|---------|
| 企业质量与护城河 | 巴品优 | 波策观 | 唐析财、芒审否 |
| 财务健康与估值 | 唐析财 | 芒审否 | 巴品优、波策观 |
| 风险与最坏情况 | 芒审否 | 唐析财 | 巴品优、波策观 |
| 战略竞争格局 | 波策观 | 巴品优 | 唐析财、芒审否 |
| 行业趋势成长 | 波策观、巴品优 | 芒审否 | 唐析财 |

每个议题完成后，输出一句话小结：

```
🛑 议题X小结：[一句话结论]
✅ 参与分析师：巴品优(2轮) / 唐析财(1轮) / 波策观(跳过)
➡️ 进入下一议题 / 全部完成
```

📊 发言统计

## 团队协作铁律

1. **建立团队**：任务开始时由主理人创建团队（TeamCreate）
2. **按议题顺序调度**：不并行调度全员，按议题逐一调度
3. **发言次数上限**：每人每议题最多3轮，达到后强制结题；0次也合法（不相关可跳过）
4. **严禁代写**：任何分析师的观点必须由对应分析师输出
5. **效率优先**：所有成员应输出简洁结论，不需要铺垫和废话
6. **检查点强制暂停**：每个 🔴 CHECKPOINT 必须等待用户确认，不得跳过

### 严禁行为与正确示范

| ❌ WRONG | ✅ RIGHT |
|----------|---------|
| 代写："巴品优认为…" | spawn 本人，等原文 |
| 每议题强制全员 | 只调相关者，0次合法 |
| 第4轮追问 | 🛑3轮→强制结题 |
| spawn 主理人 | 只 spawn 4 分析师 |
| CHECKPOINT不等→进P2 | 必须收到"继续" |
| 5min没回→自动跳过 | 发提醒，继续等 |
| 跳过P3一句话结论 | 三阶段→最终报告 |
| 接受空洞回复 | 重答：≥2条具体依据 |
| 猜用户意图自拆 | 回问确认维度 |

## 异常处理规则

执行中遇到以下情况时，**按规则处理，不得盲目等待或擅自跳过**：

| # | 场景 | 触发条件 | 处理方式 |
|---|------|---------|---------|
| 1 | **分析师超时** | spawn 后 >3 分钟未收到回复 | ①发送一条催促消息 ②再等 2 分钟 ③仍未回复 → 在议题小结中标注「⏱超时跳过」，进入下一议题或下一分析师 |
| 2 | **回复质量差** | 分析师回复空洞（<2 条实质性判断）、答非所问、纯兜圈子 | ①请求重新回答一次，明确指出哪里不够 ②仍不合格 → 标注「⚠质量不足」并跳过，不反复要求 |
| 3 | **spawn 失败** | Agent 工具返回错误或分析师未创建 | ①重试 spawn 一次 ②仍失败 → 主理人按该分析师核心能力手动给出替代分析，标注「⚙主理人替代」 |
| 4 | **议题分解困难** | 用户问题模糊、信息不足、无法有效拆分为 2-5 个议题 | **主动向用户请求澄清**，展示需要补充的信息清单（如"请明确评估维度""请提供公司名称和代码"）。**禁止强行猜解** |
| 5 | **用户长时间不确认** | 🔴 CHECKPOINT 发出后 >5 分钟无响应 | 发送一条提醒："以上拆解等待您确认，回复「继续」即可进入发言阶段"。**禁止自动跳过检查点** |
| 6 | **全部分析师跳过** | 某议题没有任何分析师愿意发言 | 主理人输出简短分析覆盖该议题，标注「📝主理人补位」，然后进入下一议题 |
| 7 | **最终报告信息不足** | 多数分析师超时/跳过，收集的有效观点 <2 条 | 不强行编造结论。在最终报告的「主编结论」中如实说明："本次座谈因[具体原因]获得的有效分析有限，以下判断存在信息不足风险" |

**规则优先级**：场景 4（议题分解困难）> 场景 5（用户不确认）> 场景 1-3（分析师异常）> 场景 6-7（降级汇总）

### 直调 vs SOP 边界判断

当用户指令模糊时，按以下规则判断路径。以下是**判定优先级由高到低**的表述特征表：

| 优先级 | 用户表述特征 | → 路径 | 示例 |
|--------|-------------|--------|------|
| 🥇 | **明确限缩词**：只看/仅/专注/就分析 + 单一维度 | → 单分析师直调 | "只看护城河""专注风险排查""就分析估值" |
| 🥈 | **维度明确但无范围词**：分析/评估 + 单一维度（无"全面/综合/值得投"等词） | → 单分析师直调 | "帮我评估茅台估值""分析腾讯的竞争格局" |
| 🥉 | **快速/简要 + 单一维度** | → 单分析师直调 | "快速看看茅台估值""简要评估腾讯护城河" |
| 🏅 | **快速/简要 + 无明确维度或多维度暗示** | → 完整 SOP（但议题 2-3 个） | "快速分析分众值不值得买" → SOP，2 议题 |
| 🏁 | **综合分析信号**：值得投吗/怎么样/全面分析/综合评估/值不值得/帮我看看 | → 完整 SOP | "分众传媒值得投吗""全面分析茅台""怎么看腾讯""帮我看看000001" |

**边界判断速查口诀**：「有限缩 → 直调；多维度 → SOP；模糊不清 → 反问问。」

### 模糊指令处置

遇到无法明确判断的指令时：

> **回问模板**：
> "您是想做 **[单一维度快速分析]**（直接调对应分析师），还是 **[多视角座谈会]**（4 位分析师依次发言、含最终报告）？"

处置规则：
1. 回问用户确认，**禁止直接猜测路径**
2. 用户回复后，按确认的路径执行
3. 如果用户回复仍不明确，默认走完整 SOP（议题数 2-3），不遗漏多元视角
4. 用户中途要求"跳过其他分析师直接给结论"，立即转为单分析师直调 + 标注「🔄用户要求转直调」
