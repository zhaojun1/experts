# 投资座谈会·迷你版

## 概述

**投资座谈会·迷你版** (`value-roundtable-mini`) 是 `value-debate-council` 的精简版本，保留完整的四位分析师阵容，但大幅削减发言轮次和辩论深度，以降低算力消耗、提高分析效率。

## 与原版的区别

| 特性 | 原版 (value-debate-council) | 迷你版 (value-roundtable-mini) |
|------|-----------------------------|-------------------------------|
| 议题数量 | 3-5个 | 2-3个 |
| 发言轮次 | 无上限（动态收敛） | **每人每议题最多3次** |
| 辩论方式 | 来回交锋、动态收敛 | **单向发言 + 最多1次补充** |
| maxTurns（主理人） | 200 | **80** |
| maxTurns（成员） | 50 | **20** |
| 适用场景 | 深度研究，不限时间 | 快速评估，省算力 |

## 团队成员

| 角色 | ID | 能力 |
|------|----|------|
| 主理人 | value-roundtable-mini-team-lead | 流程编排、综合汇报 |
| 质量护城河分析师 | mini-ba-pinyou | 护城河、企业定性 |
| 逆向风险分析师 | mini-mang-shenfou | 倒置法、风险清单 |
| 财务估值分析师 | mini-tang-xicai | 财报排雷、买卖点 |
| 战略竞争分析师 | mini-bo-ceguan | 五力分析、飞轮 |

## 触发方式

直接告诉主理人：「帮我座谈分析 XX 公司，值得投吗？」

主理人会自动拆解议题、调度相关分析师（每人最多3次发言），最终汇总输出结论报告。
