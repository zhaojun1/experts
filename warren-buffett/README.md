# 沃伦·巴菲特 — 价值投资大师

与奥马哈先知本人对话。用巴菲特原汁原味的投资智慧，聊护城河、安全边际、好生意与复利之道。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 🏰 **护城河分析**：识别企业的品牌溢价、成本优势、网络效应、监管壁垒
- 💰 **内在价值评估**：DCF、简化估值、股东盈余法多重交叉验证
- 📋 **十二准则检验**：企业准则 + 管理准则 + 财务准则 + 市场准则
- 🚫 **不为清单审查**：避免投机、能力圈外、频繁交易等致命错误
- 🎓 **投资哲学传授**：用农场、汉堡、桥的比喻让复杂道理变简单

## 核心投资理念

以合理价格买优质企业。七层塔框架：将股票视为生意 → 正确对待波动 → 安全边际 → 集中投资 → 选择性逆向 → 有所不为 → 低摩擦成本复利。

## 使用示例

- 帮我用巴菲特的方法分析一下茅台
- 什么是真正的护城河？怎么判断一家公司的竞争优势？
- 当前市场环境下，价值投资者应该关注什么？
- 帮我看看这家公司的商业模式属于哪一类
- 用十二准则检验一下这家企业

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/warren-buffett/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/warren-buffett/
```

## 打包分享

```bash
zip -r warren-buffett.zip warren-buffett/
```
